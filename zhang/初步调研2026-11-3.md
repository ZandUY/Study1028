## 二、四个方向横向比较

| 论文                                                         | 模型输出                                                     | 研究的核心问题                                               | 难度 |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ---- |
| [Benchmarking LLM Agents for Behaviorally Adequate Test Generation from Software Requirements](https://arxiv.org/abs/2610.36584) | 根据 Gherkin 需求、目标接口和项目上下文生成完整、可能跨文件的可执行 BDD 测试实现 | 如何缩小“测试能够运行”和“测试真正验证需求行为”之间的充分性差距 | 中   |
| [Natural-Language to SysMLv2 Translation via Conformance-Driven Iterative Refinement](https://arxiv.org/abs/2607.14162) | 根据自然语言系统描述生成文本化 SysML v2 模型；每轮保存候选模型、SysIDE 诊断和最终达到生产一致性的 SysML v2 工件 | 如何从“工具可加载”进一步保证需求语义正确、行为充分和跨视图一致 | 中   |
| [AutoVerus: Automated Proof Generation for Rust Code](https://doi.org/10.1145/3763174) | 在保留给定 Rust 实现和形式化规范的前提下，生成循环不变量、断言、证明函数等 Verus 证明注解，输出可被 Verus 接受的程序 | 如何利用确定性的验证器反馈提高证明合成成功率                 | 高   |
| [OntoGenix: Leveraging Large Language Models for Enhanced Ontology Engineering from Datasets](https://www.sciencedirect.com/science/article/pii/S0306457324004011) | 从 CSV 生成 OWL 本体，包括类、对象属性和数据属性；还可生成 RML 映射及 RDF 数据 | 如何让 LLM 生成的本体满足逻辑一致性和建模规范                | 中   |
